# Charters 
______ 
## Charter 1 
**Título:** 
Flujo de compra y Gestión de Stock 
______ 
**Misión:**  
Explorar el flujo de compras, utilizando diferentes productos y cantidades, para descubrir inconsistencias en la actualizacion de stock, errores en el proceso de pago y fallas en la generacion de orden, que pueden afectar las ventas y la experiencia de compra del cliente.
______ 
**Área principal explorada:** 
- Inicio/home
- Catalogo de productos
- Buqueda y seleccion de productos
- Gestion de Disponibilidad y stock de productos
- Proceso de pago
- Seguimiento del pedido

______ 
## Charter 2 
**Título:** 
Registro y Gestión de Clientes
______ 
**Misión:**                 
Explorar el proceso de registro, autenticacion y gestion de cuentas, utilizando diferente tipos de datos valido e invalidos, para descubrir errores en el proceso de validacion, autenticacion y administracion de cuentas, con el fin de garantizar un acceso seguro y confiable para el cliente
______ 

**Área principal explorada:** 
- Registrarse 
- Inicio de sesion
- Perfil del cliente
- Gestion de datos personales
- Registro de formas de pago
______
